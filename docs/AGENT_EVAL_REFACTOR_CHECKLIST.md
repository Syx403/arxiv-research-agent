## 上下文

- [x] 建立小型结构化会话状态：目标、硬约束/偏好及来源轮次、展示列表顺序与版本、已选论文、待澄清项。保存在 checkpoint，与近期原始消息共同输入。
- [ ] 当前明确要求覆盖旧要求；追问保留有效条件，换题清除不再适用条件，不推断用户未声明的硬约束。
- [ ] 以结构化列表解析“第二篇”等指代；近期原始消息作为补充，避免依赖可能被截断的回答正文。
- [ ] 按节点提供最小充分上下文；保留原始问题、解析需求、关键条件、原文句子位置及证据版本，不用历史回答充当来源证据。
- [ ] 统一上下文预算与稳定序列化；比较压缩前后正确性、输入量和延迟，不能只以减少 token 判定成功。

## 数据集与评分

- [ ] 明确每题必要要点、失败条件、适用指标和分母；未运行、未标注、评分异常单列，不能偷偷计通过或计事实错误。

- [ ] 语义评分如启用则固定 rubric、模型、来源与版本，区别于 ARA 自身 verifier；评分用量单列，可缓存重评，不默认每轮调用。
